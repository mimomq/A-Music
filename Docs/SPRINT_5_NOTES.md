# Sprint 5 Notes

## Completed in v0.5.0

- Local accompaniment now exposes elapsed time, duration, progress, and seek controls.
- MusicKit authorization is available from the Mac app.
- Apple Music catalog search returns track, artist, album, and artwork metadata.
- The Apple Music surface stays within a compliant metadata/search boundary.

## Known Product Gaps

- Apple Music playback handoff is not implemented yet.
- User library browsing is not implemented yet.
- Apple Music results are not synchronized with lyrics or scoring.
- Local accompaniment files are not persisted across app launches.

## Next Sprint

- Add MusicKit playback handoff where allowed.
- Add user library browsing.
- Add local accompaniment metadata persistence.
- Add lyrics import for user-owned local tracks.
